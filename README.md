# frogpond-client

This is a graphical client for [frogpond](https://github.com/treeplate/frogpond) - as in, a renderer for the world.

note from me committing this, a while after writing all this code: treeplate/frogpond doesn't seem to exist. the idea was basically a combination of the computer history museum's frog game and hixie's robliterator. i liked the mechanics of the frog game, as well as the overhead projector part, but didn't want to lock you in to one programming language, which is where robliterator comes in. i think part of the reason i stopped was because i ran into https://github.com/flutter/flutter/issues/138278. i don't know where the protocol spec is, if i ever made one.
